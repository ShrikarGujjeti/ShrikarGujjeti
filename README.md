### ◆ Currently building

**Trip Chalo** — a private, collaborative travel-memory platform  
`Next.js 16` `TypeScript` `PostgreSQL` `Supabase` `Cloudflare R2`

- Modular monolith with clear domain boundaries: auth, trips, memberships, invitations, media, storage, chat
- Authorization enforced in the database: Row Level Security, explicit grants, hardened `SECURITY DEFINER` functions across 22 migrations
- Server-mediated media uploads to Cloudflare R2 with presigned URLs and object verification
- Idempotent, rate-limited realtime chat; 50 attacker-style SQL security tests and ~250 automated checks gate every phase
- *Next:* semantic search over trip memories with embeddings and `pgvector`
